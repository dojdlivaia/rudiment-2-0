# Рудимент 2.0 🦖

**Твой внутренний велоцираптор реагирует быстрее, чем кора.**

Интерактивное веб-приложение для изучения когнитивных искажений и развития метапознания.

## 🎯 О проекте

Когнитивные искажения — это эволюционные эвристики. Быстрые, дешёвые, когда-то спасавшие жизнь. В современном мире они дают систематическую ошибку. Цель проекта — не избавиться от искажений (это невозможно), а научиться их замечать.

**Философия:** Не «ты ошибся», а «твой раптор сработал быстрее». Быстрая эвристика — это не глупость, это экономия ресурсов.

## 🧪 Тесты

### 1. Эффект якоря
Как случайные числа влияют на твои оценки. Даже зная об эффекте, мы не можем полностью отключить его.

### 2. Склонность к подтверждению (Confirmation Bias)
Мы ищем подтверждения тому, во что уже верим, и игнорируем противоречия. Тест показывает, какую информацию ты выбираешь для изучения.

### 3. Эффект «я так и знал!» (Hindsight Bias)
После того, как узнал результат, кажется, что предсказал бы. Тест измеряет, насколько ты переоцениваешь предсказуемость событий задним числом.

### 4. Калибровка уверенности
Насколько точна твоя самооценка? Уверенность vs правильность. Тест показывает, склонен ли ты к сверхуверенности или неуверенности.

### 5. Статистическая интуиция
Base rate fallacy, задача Монти Холла, ошибка игрока — задачи, где интуиция подводит.

### 6. Иллюзии восприятия
Мозг достраивает реальность. Тест показывает, как именно он это делает.

### 7. Башня Ханоя (планирование)
Классический тест на исполнительные функции (executive functions): планирование, рабочую память и когнитивную гибкость.

### 8. Ошибка невозвратных затрат
Продолжать ли то, во что уже вложено много ресурсов? Тест показывает, как прошлые затраты влияют на текущие решения.

### 9. Эффект формулировки
Одна и та же информация в разной подаче меняет решение. Тест показывает, как слова влияют на выбор.

### 10. Эффект доступности
Оценка вероятности по тому, что легко вспомнить. Тест показывает, как СМИ и яркие события искажают восприятие рисков.

### 11. Ошибка планирования
Оценка времени задач vs реальность. Тест показывает, насколько оптимистично мы оцениваем сроки.

## 📊 Когнитивный профиль

После прохождения тестов приложение формирует твой когнитивный профиль:

- **Радар искажений** — визуализация подверженности различным когнитивным ловушкам
- **Калибровка уверенности** — график «уверенность vs правильность»
- **Сильные стороны** — где ты хорошо калиброван
- **Зоны роста** — где стоит быть внимательнее
- **Рекомендации** — топ-3 искажения с упражнениями для тренировки

## 📈 Динамика во времени

- Прогресс по каждому искажению
- Калибровка: неделя к неделе
- Стрик (мягкий, без давления)

## 💾 Хранение данных

Все данные сохраняются в **localStorage** браузера. Это означает:

✅ Данные сохраняются при перезагрузке страницы  
✅ Данные сохраняются при публикации на GitHub Pages  
✅ Данные привязаны к конкретному браузеру и устройству  
❌ При очистке кэша/cookies данные удалятся  
❌ При открытии в другом браузере или на другом устройстве данные не перенесутся

Для кросс-девайсного хранения нужна база данных (Firebase, Supabase и т.д.).

## 🌐 Публикация на GitHub Pages

1. Создай репозиторий на GitHub
2. Запушь код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```

3. Установи GitHub Actions для деплоя. Создай файл `.github/workflows/deploy.yml`:
   ```yaml
   name: Deploy to GitHub Pages

   on:
     push:
       branches: [main]

   permissions:
     contents: read
     pages: write
     id-token: write

   jobs:
     build:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         
         - name: Setup Node
           uses: actions/setup-node@v4
           with:
             node-version: '20'
             cache: 'npm'
         
         - name: Install dependencies
           run: npm ci
         
         - name: Build
           run: npm run build
         
         - name: Setup Pages
           uses: actions/configure-pages@v4
         
         - name: Upload artifact
           uses: actions/upload-pages-artifact@v3
           with:
             path: './dist'

     deploy:
       environment:
         name: github-pages
         url: ${{ steps.deployment.outputs.page_url }}
       runs-on: ubuntu-latest
       needs: build
       steps:
         - name: Deploy to GitHub Pages
           id: deployment
           uses: actions/deploy-pages@v4
   ```

4. В настройках репозитория:
   - Перейди в **Settings → Pages**
   - В разделе **Build and deployment** выбери **Source: GitHub Actions**
   - GitHub автоматически задеплоит сайт при следующем push в main

5. Твой сайт будет доступен по адресу: `https://USERNAME.github.io/REPO/`
